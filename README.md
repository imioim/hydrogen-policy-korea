# 생산 입지 중심 경제로 본 한국 그린수소 정책의 공백과 재설계

**부제: 유럽 해상풍력 연계 수전해 사례의 입지 조건 분석**

한국 그린수소 정책을 생산 입지(立地) 중심의 관점에서 분석하는
연구입니다. 유럽의 해상풍력 연계 수전해(water electrolysis) 사례에서
입지 조건을 분석하고, 이를 통해 한국 정책의 공백을 짚고 재설계
방향을 제시합니다. 분석 대상 지역은 울산과 동해·삼척(강원) 두
수소 클러스터입니다.

연구의 투명성을 위해 분석에 사용한 데이터, 코드, 그림, 참고문헌을
공개합니다.

**현재 상태: 작성 중 (2026). 데이터·코드 공개 2026-11-09.**

## 저장소 구성

| 폴더 | 내용 |
|------|------|
| `paper/` | 논문 원고 (초안·개정본). 원고 확정 후 게시 |
| `data/` | 분석에 사용한 데이터와 코드. 상세 설명은 [`data/README.md`](data/README.md) |
| `figures/` | 그림 (풍속·수심 지도, 해저지질도 참고 화면) |
| `references/` | 참고문헌 목록·공공저작물인 법령·정책 문서. 목록 확정 후 게시 |

### `data/` 하위 구성

| 하위 폴더 | 내용 |
|------|------|
| `01_cases/` | 유럽 해상풍력 연계 수전해 사업 44건(+제외 후보 3건) 코딩표, fsQCA 입력·실행 스크립트(R)·결과 |
| `02_legal/` | EU(RED II·III, 위임규정 2023/1184·1185)와 한국(수소법·인증 고시·해상풍력법·분산에너지법·전기사업법) 조항 대조표 |
| `03_site/` | 울산·동해·삼척 후보 해역의 수심(BADA2024), 해양용도구역(해양공간관리계획 고시 공간정보), 풍황(Global Wind Atlas 3.0), 계통 접속점, 입지 순위표와 가중치 민감도 |
| `04_lcoh/` | 해상풍력 연계 수전해 LCOH 모형(Python)과 결과, 풍력·태양광 시간별 이용률(Renewables.ninja), 수입 그린수소 도착 단가 산출 시트 |

## 재현

- fsQCA: `Rscript data/01_cases/fsqca_run_v3.R` (R, QCA 패키지)
- LCOH: `python data/04_lcoh/lcoh_model_v3.py` (numpy, pandas)
- 입지 계산 절차: `data/03_site/bathymetry_zoning_v2.xlsx`의 '방법' 시트

## 포함하지 않은 자료

학술 논문 PDF와 IEA Hydrogen Production/Infrastructure Projects
Database 원본은 저작권·이용약관에 따라 포함하지 않았습니다. 출처
링크는 `data/README.md`에 있습니다.
